# Тату-студия «117» - сайт-одностраничник

Одностраничный сайт тату-студии «117» (Москва): первый экран с крупным вордмарком,
бегущая строка с ценами, принципы студии, стили работ, портфолио-слайдер,
частые вопросы и форма записи на консультацию.

**Сайт опубликован:** https://k05516268-dotcom.github.io/tattoo-117/

## Что внутри

- Авторские эскизы без копий, стерильность как в клинике, честные цены до сеанса
- Стили: олдскул, графика и орнамент, блэкворк и дотворк, минимализм
- Подарок: эскиз на консультации
- Цены: мини-работа от 3 500 ₽, крупный проект от 15 000 ₽/сеанс

## Технически

- Чистый HTML + CSS + JavaScript без сборки - открывается как есть
- Шрифты с Google Fonts: Marck Script (заголовки), Caveat (текст)
- Хостинг: GitHub Pages из ветки `main`
- Телефон, адрес и мессенджеры в блоке записи - заглушки, заменить на реальные

## Структура файлов

| Файл | Что это |
|------|---------|
| `index.html` | Вся страница: секции, форма, разметка |
| `styles.css` | Внешний вид: цвета бренда, шрифты, адаптив |
| `main.js` | Интерактив: меню, слайдер, аккордеон, форма |
| `img/` | Картинки: фон первого экрана и работы портфолио |
